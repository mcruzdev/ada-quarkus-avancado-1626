# ProjetoFinal - Test Suite

Automated test suite for validating all requirements from the Quarkus Advanced Course final project (PROJETO_FINAL.md).

## 📋 Requirements

- Java 17 or higher
- The Quarkus application running on `http://localhost:8080`

## 🚀 How to Run

Open Command Prompt or PowerShell and run:

```shell
java ProjetoFinal.java
```
